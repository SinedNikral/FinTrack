# FinTrack — система учёта личных финансов

## 1. Описание проекта

**FinTrack** — настольное приложение для учёта личных финансов, разработанное на Python с использованием библиотеки PySide6 и графического редактора Qt Designer.

Приложение предназначено для ведения учёта доходов и расходов, управления категориями финансовых операций, контроля бюджетов и анализа личных финансов.

## 2. Техническое задание

Разработать настольное приложение с графическим интерфейсом, позволяющее:

- Добавлять, редактировать и удалять финансовые операции.
- Разделять операции на доходы и расходы.
- Управлять категориями операций.
- Создавать и контролировать бюджеты по категориям.
- Отслеживать текущее финансовое состояние.
- Просматривать статистику и графики.
- Формировать отчёты в форматах PDF и Excel.
- Сохранять историю сформированных отчётов.

## 3. Используемые технологии

- **Python 3.13** — основной язык программирования.
- **PySide6** — создание графического интерфейса.
- **Qt Designer** — визуальное проектирование интерфейса.
- **SQLite** — хранение данных.
- **Qt Charts** — построение графиков.
- **OpenPyXL** — создание Excel-отчётов.
- **ReportLab** — формирование PDF-отчётов.
- **PyInstaller** — создание автономной версии приложения.

## 4. Функциональные возможности

### Главная страница

- Отображение общей суммы доходов и расходов.
- Отображение текущего баланса.
- Просмотр последних финансовых операций.
- График изменения доходов и расходов.

### Операции

- Добавление новых операций.
- Редактирование и удаление операций.
- Фильтрация по типу, категории и периоду.
- Быстрое добавление операции с помощью Ctrl + N.
- Открытие операции двойным щелчком мыши.

### Категории

- Создание категорий доходов и расходов.
- Редактирование названий категорий.
- Удаление категорий с проверкой их использования.

### Бюджеты

- Создание бюджетов для категорий.
- Контроль расходов относительно установленного лимита.
- Уведомления при использовании 80% бюджета и его превышении.

### Аналитика

- Просмотр финансовых показателей.
- Анализ доходов и расходов.
- Графическое представление финансовых данных.

### Отчёты

- Формирование финансовых отчётов.
- Экспорт данных в PDF и Excel.
- Просмотр истории сформированных отчётов.
- Открытие и удаление записей истории.

## 6. Установка и запуск из исходного кода

### Требования

- Windows 10 или Windows 11.
- Python 3.13 или совместимая версия.
- Менеджер пакетов pip.

### Получение исходного кода

Клонировать репозиторий:

```bash
git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ
```

Перейти в папку проекта:

```bash
cd FinTrack
```

### Создание виртуального окружения

```bash
python -m venv venv
```

Активировать окружение:

```bash
venv\Scripts\activate
```

### Установка зависимостей

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Запуск приложения

```bash
python main.py
```

При первом запуске приложение автоматически создаёт базу данных и необходимые таблицы.

## 7. Сборка приложения в EXE

Для создания автономной версии используется PyInstaller.

Установить PyInstaller:

```bash
pip install pyinstaller
```

Перейти в корневую папку проекта и выполнить команду:

```powershell
python -m PyInstaller --noconfirm --clean --windowed --onedir --name FinTrack --add-data "ui;ui" --add-data "resources;resources" --collect-all PySide6 --collect-all shiboken6 --collect-all reportlab --collect-all openpyxl --exclude-module PyQt5 --exclude-module PyQt6 --exclude-module PySide2 main.py
```

После успешной сборки готовое приложение будет находиться в папке:

```text
dist/FinTrack/
```

Для запуска необходимо открыть файл:

```text
FinTrack.exe
```

**Важно:** используется режим `onedir`, поэтому для корректной работы приложения необходимо сохранять всю папку `FinTrack`, включая каталог `_internal`. Передавать только файл `.exe` нельзя.

### База данных в готовой версии

При первом запуске приложение создаёт базу данных `fintrack.db` рядом с исполняемым файлом.

Если необходимо перенести существующие данные, нужно скопировать файл `fintrack.db` из исходного проекта в папку `dist/FinTrack/` рядом с `FinTrack.exe`.

## 8. База данных

Для хранения информации используется SQLite.

База данных содержит таблицы для хранения финансовых операций, категорий, бюджетов, настроек приложения и истории отчётов.

Работа с базой данных включает добавление, чтение, изменение и удаление записей (CRUD).

## 9. Архитектура приложения

Проект разделён на несколько логических модулей:

- **database** — взаимодействие с базой данных.
- **pages** — контроллеры страниц приложения.
- **dialogs** — диалоговые окна для ввода и редактирования данных.
- **ui** — интерфейс, созданный в Qt Designer.
- **resources** — графические ресурсы приложения.
- **services** — дополнительные сервисные компоненты, если они используются в проекте.

Такое разделение упрощает сопровождение и дальнейшее развитие проекта.
